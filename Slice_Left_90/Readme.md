# Repository for Left 90 Slice board submission.

1. Download Slice Board Example and open in KiCAD. Become familiarized with the components in the schematic and where they're laid out.
2. Edit the PCB so the data out connector is one edge clockwise from the data in connector (if looking at the PCB from the top; data lines make a 90 degree left turn). Keep the connectors within 2cm from their respective edges.
3. Modify as needed to give your own personal touch, i.e. layout changes, artwork, name / date blocks.
4. Keeping the same file structure as shown in the Slice board example page, generate the project gerber and drill files into the "Gerber" folder. Create a .zip file of the documents and upload into this page.
